      Airtable
      Make a token at airtable.com/create/tokens ↗
      1. Click Create token and give it a name, like “Joiner”.
      2. Add the scopes data.records:read and schema.bases:read.
      3. Under Access, add the bases you want to map, then copy the token and paste it here.

      Treat a token like a password: anyone who has it can read those bases. Keep it out of emails, chats and shared docs. If one gets out, delete it on that same page and make a new one. Joiner keeps it only in this tab until it closes, and sends it only to Airtable.
